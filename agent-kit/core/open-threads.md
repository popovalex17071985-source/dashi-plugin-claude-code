# Open threads — the single board

Every promise, project and next step lives here. Nothing else is a board.

Rules:
- Write in PLAIN language the operator can read. Say what it means for them, not
  which file changed. Technical detail goes at the END of the line, if at all.
- One line = one thread. `- [ ]` open, `- [x]` closed.
- A deadline goes as a date the sweeper can see: `к 28.08`, `до 28.08`, `пт 28.08`.
- Any forward promise ("I'll come back with…", "later", "let's defer") lands here
  in the SAME turn it was made. The capture hook is a backup, not the plan.
- Check the ledger when returning to a topic; close threads as they finish.
